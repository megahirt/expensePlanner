Privacy policy

expensePlanner (the Chrome extension) · Last updated November 13, 2026

The short version

The extension collects no data. It does not transmit, sell or share anything. There is no server, no account and no analytics. Everything it reads stays in your own browser, on your own computer.

What the extension stores

When you import a file or run an Amazon import, the extension saves the resulting records in your browser's local storage for the extension:

  • transaction dates, descriptions, merchant names, amounts and currencies
  • account labels you type in
  • Amazon order numbers, item names, prices and whether an order was returned or cancelled
  • categories, rules, notes and tags you create
  • a history of your imports, so they can be undone

This data is kept in your Chrome profile on this computer. It is not synced to a Google account, and neither the developer nor anyone else can reach it.

The extension also includes a made-up demo household, for trying it out. That data ships inside the extension, describes no real person or account, and is kept in a separate local database from anything you import.

What the extension sends

Nothing. The extension makes no network requests to any server run by the developer or by any third party. It has no analytics, telemetry, crash reporting or ads.

Website access

The extension asks for access to https://www.amazon.com/* as an optional permission, so it has no access to any website when installed. Access is asked for only at the moment you click Import from Amazon. It is used only to read your own order history pages, which Amazon offers no export for, and to save the order details locally. The extension never sees your Amazon password.

You can take this access back at any time at chrome://extensions.

Bank and credit card data is never read from any website. It enters the extension only through CSV files that you download from your bank and choose to open. Your bank password is never asked for.

Files you export

CSV and backup files you export are written to your computer's downloads folder by your browser. They are not uploaded anywhere. If you send such a file to someone, that is your own action, outside the extension.

Deleting your data

Settings → Delete all my data removes every record described above at once. Uninstalling the extension also removes it. Save a backup first if you want to keep anything.

Changes to this policy

If this policy changes, the new version will be posted on this page with a new date.

Contact

Questions or concerns: open an issue on the project's GitHub page.
